## About Icons
These icon files are based on the official Love2D logo graphics published by the project on its website.

Source: [Love2D Website](https://www.love2d.org/wiki/L%C3%B6ve_Logo_Graphics)

They are used here as the application/window icon for this project and are included to help identify the game in the desktop environment and launcher.

Please refer to the original Love2D logo page for the most up-to-date asset details and licensing information.
